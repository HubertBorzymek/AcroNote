## 🚀 Instalacja (Windows 10/11, 64-bit)

1. Pobierz plik **`AcroNote-…-win-x64.zip`** z sekcji *Assets* poniżej.
2. Rozpakuj całe archiwum (prawy przycisk → *Wyodrębnij wszystkie*).
3. Kliknij dwukrotnie **`AcroNote.bat`**. Przeglądarka otworzy się sama pod adresem http://localhost:3001

Nie trzeba instalować Node.js ani niczego innego, bo wszystko jest w paczce. Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij *Więcej informacji → Uruchom mimo to*.

**Konta demo** (tworzone przy pierwszym uruchomieniu): `demo` / `AcroNote-demo-2026` oraz `trener_demo` / `AcroNote-trener-2026`.

Dane są zapisywane w `%LOCALAPPDATA%\AcroNote`, więc aktualizacja do nowej wersji ich nie usuwa.
